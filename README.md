# Itqan — إتقان

## AI-Powered Quran Recitation Coach

King Saud University — Information Systems Department  
Graduation Project — IS498 / IS499

### Overview
Itqan is an AI-powered Quran recitation coaching system designed to help Quran readers improve their recitation through intelligent, interactive assistance.

The current graduation-project scope is a **standalone application focused on Juz Amma (37 Surahs)**.

### Target Users
- Anyone who reads the Quran and wants to improve their recitation, pronunciation, Tajweed, reading, or memorization.
- Children, particularly through **Al-Mushajji (Encourager)**.
- Quran learners/students.
- Quran teachers through **Al-Mu'allim (Teacher)**.

### Core Experience
Select Surah → Recite → AI analyzes → Feedback / Smart Prompting → Progress updated.

### Approved AI Modes
- **Al-Mujawwid (المُجَوّد):** recitation, pronunciation, and Tajweed improvement.
- **Al-Mushajji (المُشجّع):** motivation, challenges, and rewards, particularly for children.
- **Al-Mu'allim (المُعلّم):** teacher-oriented student progress and performance monitoring.

### Current Scope
- Standalone Itqan application.
- Juz Amma — 37 Surahs.
- Recitation and AI analysis.
- Pronunciation/Tajweed error detection as a project goal.
- Feedback and Smart Prompting.
- Progress tracking and Mastery Score.
- The three approved AI modes.

### Future Vision
- Integration with other Quran applications/platforms.
- Integration with AI agents.
- Expansion beyond Juz Amma to the full Quran.
- Other future features may be added, modified, or removed as the project evolves.
